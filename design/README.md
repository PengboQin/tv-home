# 交互设计稿 · 非已实现功能

最新结构稿为 [ha-study.html](ha-study.html)：桌面、家庭、应用、设置四个常驻底部标签，家庭等页使用可折叠上下文侧栏，展示天气、开关和自动化。所有状态和动作均为合成演示，不访问 HA 或真实设备。它用于评审未来 Android 原生界面，不是准备嵌入 App 的网页，也不是已安装的功能。见[状态与路线图](../docs/STATUS.md)、[HA 接口契约](../docs/HA-CONTRACT.md)和[统一素材](system/README.md)。

`native-study.html` 是上一轮单层顶部导航探索；`suite.html`、`next-study.html` 是更早的完整场景探索。保留用于比较取舍，不把多个方向合成已实现功能列表。

历史 [suite.html](suite.html) 包含家庭页/HA全屏、App列表与网格、网页入口、搜索、整理、连接、闲置、帮助、组件和七类设置，以及离线/登录过期等场景。所有家庭数据和App列表均为合成演示；不会连接HA、查电视或控制家电。原生能力以根README的表格为准。

在仓库根目录运行：

```sh
python3 -m http.server 8776 --bind 127.0.0.1
```

用浏览器打开 `http://127.0.0.1:8776/design/ha-study.html`，可用方向键/Enter/Escape或点击评审控件切场景；原型内 MENU 对应 M 键。预览存储只在本浏览器localStorage，不是电视配置。退出预览后停止该终端进程；已有服务占用端口时换端口，不杀其他项目服务。

样例页面展示整套思路，尚有布局/焦点细节待继续完善。使用的内置壁纸在 `../assets/`，没有外部字体/CDN/第三方JS依赖。源码中少量 `.mac` 样式是早期探索遗留，当前入口只提供Android TV设计，不表示有Mac桌面客户端。全局“概览”链接回本说明；暂不捆绑历史截图画廊以避免重复大文件和混淆。
