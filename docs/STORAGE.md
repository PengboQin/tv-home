# 项目体积与保留

源代码/文档、单份规范壁纸和当前设计源码纳入Git。固定 `build/` 可重建；`artifacts/` 保留公开候选及上一份真正验证过的恢复候选，发行元数据留 `releases/`。

`.private/`（签名）和 `local/`（用户设备配置/授权证据）忽略且不可当缓存删除；本项目不持有真实家庭配置。签名的离线备份由维护者私下管理，绝不上传。不要复制完整工程做逐轮备份，不清共享SDK/JDK或其他项目目录。

默认可重建产物5GiB预警/10GiB上限；这个小型工程无需庞大缓存。清理前核对当前候选/恢复链/运行进程；仅删明确可重建且归属本项目的内容。首次公共整理约几MiB源素材，测量和公开哈希校验记录留在维护者忽略的local/，不上传设备原始证据。未使用模拟器；无新增常驻服务。
