# 具体风险与边界

这不是对任何固件的安全保证。普通 App 的边界降低了修改系统的风险，但屏幕卡死、进程崩溃、数据丢失和误操作仍可能发生。请先确保原厂遥控器、系统 Home 和设置能用。

| 场景 / 机制 | 可能影响 | 如何降低风险 / 出问题时 |
| --- | --- | --- |
| ADB 电脑授权，尤其传统 TCP 调试 | 被授权电脑可执行较广的 shell/安装/按键操作，远超 App 的 INTERNET 权限；网络泄露或电脑被控会扩大风险 | 仅可信电脑和局域网；不做公网映射、不交未知云 Agent；显式目标；测试完按用户选择关闭调试/撤销授权。Android TV 的配对/加密机制随版本不同，勿假设 5555 安全 |
| Agent 自动执行网页/日志中的指令 | 页面文本可诱导错误命令、泄露数据或越权控制 | 页面/日志/Issue 只当数据；人类给范围，写入前核对目标和动作；绝不开放通用 shell 网络端点 |
| 安装/更新 APK | 固件可能拒绝，签名/版本不兼容可能阻断更新；错误卸载会丢配置和网页登录状态 | 官方工具、版本/哈希/签名核验；保留原包；失败停止，不绕签名、不自动卸载 |
| 默认桌面/系统包改动 | 可能失去 Home/设置入口或影响输入源、启动、遥控器 | 当前没有 HOME/开机接管；不禁用原厂桌面、不 debloat、不刷机。将来要做默认 HOME 必须单独方案/验收，本仓库不教一键替换 |
| App/系统 WebView 崩溃或资源占用 | 卡住、黑屏、网页加载失败；老电视内存/图形驱动差异 | 返回/Home退出，必要时仅 force-stop 本 App；安全启动暂不加载 HA。不保证 ANR、系统崩溃、掉电都留下记录 |
| Java 崩溃安全模式与诊断 | 只覆盖部分错误；本机崩溃记录/事件时间仍可能反映使用时间 | 记录类名/栈/版本，不记录异常消息、URL、输入文本或 token；只在本机，勿直接发 raw log。公开包 debug=false，不提供主动崩溃按钮 |
| HA 登录后的控件 | 按确认可能真的开灯、开门、运行自动化，页面不是只读 | 人类登录，不收集 token；先本地测试页。用户确认具体家电动作前不点控件；HA 服务端权限由 HA 决定，隐藏卡片不等于安全只读权限 |
| HTTP、旧 WebView、第三方 HA 卡片 | HTTP可能泄露会话/内容；旧内核可能有漏洞或不支持新页面；页面可加载外部 HTTPS 资源 | 优先可信 HTTPS；HTTP仅接受私网 IPv4并非加密。不要绕 TLS警告；只装可信卡片，不将同源过滤称为防火墙；不要自动更新系统 WebView/固件 |
| WebView 会话与共享电视 | 本地 DOM 存储/cookie可能保留登录；任何能操作电视的人可能使用已登录页面 | 仅可信家庭设备；用 HA 实际支持的最小权限；离开/转让前在 HA 注销会话。App allowBackup=false不是数据加密承诺；不保证退出App就清cookie |
| D-pad/返回/长按、蓝牙/红外/手机遥控器 | 相同按键在厂商固件、不同App和网页中行为不同；可能误触、焦点不可达 | 逐条实测，不把ADB事件当实体遥控器验证；App保留系统键、不全局拦截；HA不适合遥控器时停止而非模拟乱点 |
| HDMI/CEC/光纤音频与输入源 | 切换App/输入源可能被系统/CEC影响，音量条变化不一定改变光纤音响实际响度 | 当前App不修改这些系统设置；原型一次验证不保证所有设备。使用原厂操作路径；Mac/Apple TV的系统音量控制不是这个Android桌面的功能 |
| 升级/降级与签名丢失 | 新版配置可能无法被旧版读取；签名不同不能覆盖；旧版可能更不安全 | 保留同签名兼容候选、版本记录与必要配置恢复；降级不保证数据恢复，不自动uninstall/clear；见RECOVERY |
| 第三方桌面Agent/无障碍/远程服务 | 可能读屏幕、帐号和整机操作，增加攻击面和持续访问 | 当前未集成；不能为“支持Agent”默认安装辅助功能服务。单独评估授权、身份认证、最小动作、过期撤销、本地限定后再探索 |

## 代码确实做了什么

原生 App 只请求 INTERNET；没有 HOME 类别、服务、receiver 或原生 `.so`。浏览器允许 HTTPS 或私网 IPv4 HTTP、拒绝 URL userinfo；主框架导航按配置同源处理，阻止跨源 HTTP 子资源，禁用 file/content访问、第三方cookie和自动多窗口，无 JS→Java 桥，下载只提示。

这**不构成完整的网页安全沙盒**：JavaScript/DOM storage 为 HA 启用，HTTPS 子资源可能来自外部域名，网络权限没有域名级防火墙；允许的 URL 可带 query/fragment，用户不要在任何 URL 放 token。DNS、重定向、已登录页面内容、系统 WebView 漏洞都不由简单 URL 校验消除。应用里的网页服务书签用外部浏览器打开，其权限/会话由该浏览器管理。

## 问题反馈前

不要公开电视IP/MAC/序列号、真实HA地址、家庭布局/实体名、账号、cookie/token、ADB私钥或签名文件。即使是本地IP也不需要作为兼容性报告的一部分。报告型号、系统/固件/WebView版本、App版本/哈希、脱敏复现步骤即可。可公开复现的问题通过 Issue；涉及凭据泄露先撤销凭据，不要把秘密贴出来。没有承诺专用保密收件渠道。

参考：[Android ADB](https://developer.android.com/tools/adb)、[TV App 创建](https://developer.android.com/training/tv/get-started/create)、[WebView](https://developer.android.com/develop/ui/views/layout/webapps/webview)。这是项目实施边界，不能替代厂商对具体设备的支持。
