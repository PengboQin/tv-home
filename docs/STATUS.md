# 当前状态与下一阶段

2026-10-23。本次是源码、设计和文档同步，没有发布新 APK；已有 Releases 下载仍为 0.1.0-preview.1。源码中的 versionCode 4 / 0.1.2-preview.2 与下载包版本不同。

## 哪些已经实现

普通 LEANBACK App，不替换系统 HOME。现有原生左侧导航为家庭、应用、服务、设置、退出五项，可收缩，应用内切页保留单个 WebView；四列已安装 App 入口、时钟、静态内置背景、网页全屏及返回入口、故障后的安全加载与恢复、有限图标缓存。没有新设计稿的四标签底栏或原生 HA 控件，也没有新增整机权限、跨 App 内容抓取或常驻 Agent 服务。

本地开发候选完成过有限的电视布局、本地示意页与虚拟方向键检查；这不能替代实体遥控器、真实 HA 家电操作、其它品牌或长时间运行验收。旧网页方案对遥控器的适配仍不足，不能把网页可加载称为遥控器可操作。

## 新方向：HA 是后端，电视使用原生界面

每位使用者填写自己的局域网 HA 地址并完成本人授权，不需要作者家的实体 ID、账户或私有服务。优先支持天气、light/switch 控制、automation 启停与状态，按可用区域信息分组。保留完整原网页为可选入口，不自动解析或复制每家的 Lovelace 自定义卡片。

- 全局底部四标签：桌面、家庭、应用、设置。
- 上下文侧栏可折叠，提供当前标签内部的分类；桌面无需侧栏。
- 遥控器焦点、返回落点与离线/不可用/未确认状态有明确设计，不接管系统音量或输入源键。
- 状态来自 HA，发出请求不等于设备动作成功；不自动重发家电写操作。

当前已提供 [HA 接口契约](HA-CONTRACT.md)、[合成数据模型与交互稿](../design/ha-study.html)、统一设计 tokens 和 26 个 SVG/Android 矢量素材。已有模型测试和素材一致性检查。**Android 原生 HA 网络客户端、正式授权流程和真实实体操作尚未实现。** HTML 设计稿不会安装进电视，也不连接真实 HA。

## 下一步

先落实原生页面和焦点，再接入真实 HA 只读状态，最后在明确目标和用户授权下验证少量控制。自动发现不等于自动开放全部开关，初次应选择允许控制的实体。内置浏览器登录状态不作为原生 API 凭据来源。

Agent 配置指南、风险及恢复步骤继续适用：[Agent 指南](AGENT-QUICKSTART.md)、[风险](RISKS.md)、[恢复](RECOVERY.md)、[验证边界](VALIDATION.md)。当前没有插件执行器、开放 shell 或远程控制端口。Mac 音量键软件是独立项目：[TV Volume Keys](https://github.com/PengboQin/tv-volume-keys)。
